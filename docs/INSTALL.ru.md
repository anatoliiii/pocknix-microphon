# Установка: порядок действий

Полные команды и развилки: [INSTALL.md](INSTALL.md). Здесь порядок на русском.

1. Убедитесь, что это Flip2 SM8250/WCD9385 и похожий симптом: источник виден, но
   PCM превращается в нули. Сохраните рабочие динамики и резервную копию SD/boot.
2. Получите **точные исходники, config, toolchain и Module.symvers своего ядра**
   из сборки PockNix. Одинакового uname -r недостаточно для гарантии ABI.
3. Просмотрите wcd938x.c. Патч 0002 нужен, если при физическом DMIC3 (shift=2)
   отсутствует установка BIT(7) регистра 0x345d и снятие этого бита при выключении.
4. Если состояние switches ещё хранится по portidx, рассмотрите 0001. Если уже
   используется фактическая ch_mask, не заменяйте её локальным обходным решением.
   Его ограничение — алиасы MBHC/DMIC2; одновременный захват с гарнитурой не проверен.
5. Проверьте mono только для TX_CODEC_DMA_TX_3 (условный патч 0003), DT-маршрут
   DMIC3 и Mic UCM. Фрагменты в config нужно объединять с вашей конфигурацией,
   сохраняя динамики/наушники. Не заменяйте целиком audio-routing коротким списком.
6. Применяйте патчи через git apply --check, затем git apply. При несовпадении
   остановитесь и изучите различия; не заставляйте патч применяться вслепую.
7. Для WCD-only используйте stage-module.py и make из английской инструкции.
   Для machine module/DT используйте штатную сборку PockNix для этой платы.
8. Проверьте MODPOST, импорты, vermagic, архитектуру/config, подпись при её
   необходимости. Сохраните старый модуль, SHA256, путь и команды отката.
9. Установите модуль, depmod; если он находится в initramfs — обновите initramfs
   штатным способом. Не пишите несжатый ELF поверх .ko.zst/.ko.xz.
10. Сохраните build ID, выполните sync и перезагрузитесь вручную. Не выполняйте
    SoundWire unbind/rebind. После загрузки проверьте именно загруженный build ID.
11. Запустите [проверку тонов и речи](VALIDATION.md). Скрипт ждёт Enter перед
    стартом, чтобы момент записи был понятен. Подтвердите, что тоны реально слышны.
12. Повторите после второй отдельной загрузки. Только тогда считайте ремонт
    подтверждённым. Не маскируйте IRQ и не читайте полный master debugfs dump.

[Откат](ROLLBACK.md): вернуть сохранённый модуль в исходный путь, depmod,
обновление initramfs при необходимости, sync и ручная перезагрузка. DT/UCM
откатывать лишь если вы их меняли. Готового универсального .ko здесь нет.
