# Восстановление микрофона Retroid Pocket Flip2 в PockNix

[English](README.md) · [Установка](docs/INSTALL.ru.md) · [Результаты](docs/VALIDATION.md)

Решение проверено на **Retroid Pocket Flip2, SM8250/WCD9385, PockNix, ядро 7.2.0**:
микрофон записывает речь и включаемый/выключаемый тон 1 кГц после двух отдельных
загрузок. Обычные записи проходят без новых ошибок шины; динамики работают.

Проблема: источник микрофона виден, но запись после начального импульса содержит
нули. В Linux отсутствовало включение левого входа DMIC2: **бит 7 регистра 0x345d**,
нужный физическому DMIC3. Заводской драйвер эту операцию выполняет.

Маршрут: `WCD DMIC3 → SWR_DMIC2 → TX DEC0 → TX_CODEC_DMA_TX_3 → MultiMedia3`.
Нумерация физического DMIC, SoundWire и регистра различается.

1. Прочитайте [инструкцию](docs/INSTALL.ru.md) и проверьте исходное состояние.
2. Применяйте только отсутствующие исправления. Если маршрут, mono TX_3 и учёт
   каналов уже исправлены, нужен только патч 0002.
3. Соберите модуль под точные исходники/config/ABI своего ядра; сохраните откат.
4. После загрузки проверьте реальные тоны и речь, затем повторите после второй.

В репозитории есть патчи, фрагменты конфигурации, инструкции, скрипты проверки,
таблица измерений и откат. Личных записей, заводских бинарников и готового модуля
под чужое ядро нет. На других моделях и ядрах решение не проверено.

Первоначальный эксперимент прошёл на одном устройстве; это не универсальный
установщик и не официальный релиз PockNix. Статический шум не считается успехом.
